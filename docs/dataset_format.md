# 数据集格式说明（KITTI 标准）

> 本项目采用 **KITTI** 格式。理由：这是自动驾驶领域最通用的标注格式，以后想和公开方法对比可以直接用。

---

## 一、目录结构

```
dataset/
├── image_2/             车载相机 RGB 图
│   ├── 000000.png
│   ├── 000001.png
│   └── ...
├── label_2/             每帧的真值标注（一行一个目标）
│   ├── 000000.txt
│   └── ...
├── calib/               每帧的内参矩阵
│   ├── 000000.txt
│   └── ...
└── meta.json            采集参数（相机、地图、帧数、时间）
```

**命名规则**：`image_2` / `label_2` / `calib` 三者**同名对应**（`000000` 是一组）。

## 二、`label_2/*.txt` 的 15 个字段

每行一个目标，空格分隔：

```
Car 0 0 -1.5708  350.50 180.20 620.80 400.10  1.5200 1.6800 4.0900  -1.2000 1.5500 25.3000  -1.5708
 ↓   ↓ ↓   ↓        ↓      ↓      ↓      ↓       ↓      ↓      ↓        ↓      ↓      ↓        ↓
 ①   ② ③  ④        ⑤      ⑥      ⑦      ⑧       ⑨      ⑩      ⑪        ⑫      ⑬      ⑭        ⑮
```

| # | 字段 | 含义 | 单位 | 本项目的取值 |
|---|---|---|---|---|
| ① | `type` | 类别 | — | 统一为 `Car`（所有 `vehicle.*`） |
| ② | `truncated` | 截断程度（0–1） | 比例 | 固定 `0`（仿真里无人工截断标注） |
| ③ | `occluded` | 遮挡程度（0/1/2/3） | 等级 | 固定 `0` |
| ④ | `alpha` | 观测角（-π ~ π） | 弧度 | 由 `ry - atan2(x, z)` 近似 |
| ⑤ | `x1` | 2D 框左上角 x | 像素 | 3D 角点投影后取 min |
| ⑥ | `y1` | 2D 框左上角 y | 像素 | 同上 |
| ⑦ | `x2` | 2D 框右下角 x | 像素 | 投影后取 max |
| ⑧ | `y2` | 2D 框右下角 y | 像素 | 同上 |
| ⑨ | `height` | **3D 高度** | 米 | `2 × bounding_box.extent.z` |
| ⑩ | `width` | **3D 宽度** | 米 | `2 × bounding_box.extent.y` |
| ⑪ | `length` | **3D 长度** | 米 | `2 × bounding_box.extent.x` |
| ⑫ | `x` | **3D 中心 x**（相机系，右为正） | 米 | `transform` 变换后的相机局部坐标 |
| ⑬ | `y` | **3D 中心 y**（相机系，下为正） | 米 | 同上 |
| ⑭ | `z` | 🔴 **3D 中心 z = 真值距离**（相机系，前为正） | 米 | **测距的真值来源** |
| ⑮ | `ry` | 绕 Y 轴朝向（相机系） | 弧度 | `-(yaw_obj - yaw_cam)` 归一化 |

### 🔴 最重要的一句

> **第 ⑭ 个字段 `z` 就是真值距离（米）。**
> 所有测距误差都是拿你的估计值和它比：
> `相对误差 = |D_估计 − z| / z`

## 三、坐标系约定

### 3.1 三个坐标系

| 坐标系 | 原点 | 轴方向 |
|---|---|---|
| **世界坐标** | 地图原点 | x 北、y 东、z 上（CARLA 约定） |
| **相机坐标（CARLA 局部）** | 相机光心 | x 前、y 右、z 上 |
| **相机坐标（KITTI）** | 相机光心 | **x 右、y 下、z 前** |

### 3.2 为什么 KITTI 的轴和 CARLA 不一样

KITTI 采集时用的是**车载相机**，它的坐标约定跟机器人学里的「相机系」一致：**z 轴是光轴（朝前），x 向右，y 向下**（右手系）。

CARLA 用的是 UE 的约定：**x 前、y 右、z 上**（左手系）。

**转换关系**：

```
X_kitti =  y_cam      （右）
Y_kitti = -z_cam      （下，因为 CARLA 的 z 是上）
Z_kitti =  x_cam      （前）
```

**这就是 `code/collect_dataset.py` 里 `world_to_camera_kitti()` 干的唯一一件事。**

## 四、`calib/*.txt` 的格式

```
P2: 640.000000 0.000000 640.000000 0.000000 0.000000 640.000000 360.000000 0.000000 0.000000 0.000000 1.000000 0.000000
```

**12 个数，按行展开就是 3×4 的投影矩阵**：

```
P2 = | fx   0   cx   0 |     | 640    0   640   0 |
     |  0  fy   cy   0 |  =  |   0  640   360   0 |
     |  0   0    1   0 |     |   0    0     1   0 |
```

### 内参从哪来

```python
fx = (width / 2) / tan(FOV / 2)      # 1280, FOV=90° → 640
cw = width / 2                        # 640
cy = height / 2                       # 360
```

**`fx = 640` 的物理含义**：

> **距离相机 1 米处、1 米高的物体，在图像上占 640 个像素。**

### 投影公式

```
u = fx · X / Z + cx
v = fy · Y / Z + cy
```

**除以 Z 就是透视** —— 远的物体 Z 大，投出来的像素坐标离中心近（看起来小）。

## 五、`meta.json`

```json
{
  "scene": "Carla/Maps/Town10HD",
  "frames": 20,
  "attempted_ticks": 20,
  "camera": {
    "width": 1280, "height": 720, "fov": 90.0,
    "fx": 640.0, "fy": 640.0, "cx": 640.0, "cy": 360.0
  },
  "kitti_type": "Car",
  "min_dist": 1.0,
  "max_dist": 60.0,
  "synchronous": true,
  "fixed_delta_seconds": 0.05
}
```

**用途**：复现时能知道"当时用了什么参数"，不用去翻脚本。
